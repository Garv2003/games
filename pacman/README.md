# Pac-Man

A browser Pac-Man clone — navigate the maze, eat all the dots, and avoid the ghosts.

**Play:** arrow keys to move Pac-Man; clear the maze without being caught.
**Tech:** vanilla JS + HTML5 Canvas (`pacman.js`, `game.js`, `ghost.js`).
**Run:** open `pacman.html` in a browser.

> Adapted from the open-source `pacman-js` project (original author's code retained).
