# Piano

A browser piano — click the keys (or use the keyboard) to play notes with real audio samples.

**Play:** click/press keys to play notes.
**Tech:** vanilla JS + HTML/CSS, audio samples in `audio/`.
**Run:** open `index.html` in a browser.
