# Tetris

A browser Tetris clone — falling tetromino pieces you rotate and drop to clear full rows.

**Play:** arrow keys to move/rotate, down to soft-drop; clear lines to score.
**Tech:** vanilla JS + HTML/CSS (`script.js`, `pieces.js`).
**Run:** open `index.html` in a browser.

> Built by following a JavaScript tutorial — [YouTube walkthrough](https://youtu.be/oNjkDTOj-n8).
