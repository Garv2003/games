# Snake Pong

A mashup of Snake and Pong — a snake game where the food bounces around like a Pong ball.

**Play:** arrow keys to steer the snake; catch the moving food to grow and score.
**Tech:** vanilla JS + HTML/CSS.
**Run:** open `index.html` in a browser.

> Built by following a JavaScript tutorial — [YouTube walkthrough](https://youtu.be/jyhtQSjEP4s).
